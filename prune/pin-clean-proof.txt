      CSRFile/PTW/Rocket (all configs) and, on the Saturn shell, DTLB_2, RocketTile,
      SaturnRocketUnit, SaturnRocketFrontend, Iterative/PipelinedFaultCheck:
      - assertion $error strings carry new rocket-chip source line numbers;
      - PTW/DTLB temporaries renamed (ae -> _ae_T, _T_14 -> _T_13): rocket-chip c1dda58 and
        118ba74 change only guest (hypervisor) translation, absent here. With those two
        renames and the $error text normalised, CSRFile/PTW/Rocket of the non-vector
        shells are identical (0 lines);
      - Saturn shell: rocket-chip 42b7698 "Vector CSR altfmt" splits vtype.reserved[54:0]
        into reserved[53:0] + altfmt (vtype bit 8), threaded through RocketTile and
        Saturn's ports; a vsetvl with vtype[8] = 1 no longer sets vill. GCC never sets it.
      - *.graphml is renamed *.chiptop0.graphml by upstream; *.fir and *.d follow source.
      Saturn e73d9bc compiles unchanged against rocket-chip ece7b9a and shuttle 622f08b.

--- cmp-gen.py
#!/usr/bin/env python3
"""cmp-gen.py OLD_GEN_DIR NEW_GEN_DIR : compare two Chipyard generated-src config dirs.

Normalises what legitimately differs between two checkouts: absolute paths of
the checkout, and firtool source locators (// @[file:line:col]) and
`// file:line` comments, which name Scala files that moved. Everything else
must match byte for byte."""
import re, sys, hashlib
from pathlib import Path

old, new = Path(sys.argv[1]), Path(sys.argv[2])
roots = [str(p) for p in sys.argv[3:]]
LOC = re.compile(r"\s*// @\[[^\]]*\]")
LOC2 = re.compile(r"@\[[^\]]*\]")

def norm(path: Path, other_roots):
    try:
        t = path.read_text(errors="replace")
    except Exception:
        return path.read_bytes()
    for r in other_roots:
        t = t.replace(r, "<ROOT>")
    t = LOC.sub("", t)
    t = LOC2.sub("@[]", t)
    return t

def files(d):
    return {str(p.relative_to(d)).replace(d.name, "<CFG>"): p for p in d.rglob("*") if p.is_file()}

fo, fn = files(old), files(new)
only_o = sorted(set(fo) - set(fn)); only_n = sorted(set(fn) - set(fo))
same = diff = 0
diffs = []
for k in sorted(set(fo) & set(fn)):
    a, b = norm(fo[k], roots), norm(fn[k], roots)
    if a == b:
        same += 1
    else:
        diff += 1; diffs.append(k)
print(f"{old.name}: {same} identical, {diff} differ, {len(only_o)} only-old, {len(only_n)} only-new")
for k in only_o: print("  only-old", k)
for k in only_n: print("  only-new", k)
for k in diffs: print("  DIFF", k)
--- cmp-elf.sh
#!/bin/bash
# cmp-elf.sh OLD.elf NEW.elf : compare the allocated sections of two ELFs.
SDK=/scratch2/loren/riskybird-dev/backends/zephyr-chipyard-sw/tools-manual/zephyr-sdk-1.0.0-beta1/gnu/riscv64-zephyr-elf/bin/riscv64-zephyr-elf
T=$(mktemp -d)
for w in old new; do
  e=$1; [ $w = new ] && e=$2
  $SDK-readelf -SW $e | awk '/^ *\[/ && $0 ~ / A/ {gsub(/^ *\[ *[0-9]+\] /,""); print $1, $3, $5}' | grep -v "^NULL" > $T/$w.sec
  $SDK-objcopy -O binary --only-section='*' $e $T/$w.bin 2>/dev/null
done
echo "sections (name addr size):"; diff $T/old.sec $T/new.sec && echo "  identical layout"
for s in $(awk '{print $1}' $T/old.sec); do
  for w in old new; do e=$1; [ $w = new ] && e=$2; $SDK-objcopy -O binary -j $s $e $T/$w.$s 2>/dev/null; done
  cmp -s $T/old.$s $T/new.$s && r=same || r=DIFF
  echo "  $s $r $(stat -c %s $T/old.$s 2>/dev/null) $(stat -c %s $T/new.$s 2>/dev/null)"
done
rm -rf $T
